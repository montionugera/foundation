- **K4** Config refers to a secret by its source only (SECRET SOURCES): `env()`,
  `file()`, or `secret()`. Values never appear in config files, plans, or output.
  Until #239, the file store keeps each value of `secret()` in a file of its own in the
  data directory (SECRET STORES AS ADAPTERS). Secrets are write-only (`secret set`,
  `secret delete`). `plan` checks that every source of a connector on the planning
  node that the subject of the plan may apply resolves (`secret.unresolved`, SECRET
  SOURCES), and a connector on another node is not checked until #239. Agents wire
  sources but never see values.
