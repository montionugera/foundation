- **K3** Files in Git are the desired mesh; the spec is the running mesh. Commands:
  `discover`, `browse`, `import`, `plan`, `apply <plan>` (commits exactly the reviewed
  plan; refuses if the spec changed; compare-and-swap on the pointer), `explain`, and
  `export`. Each has `--json` with stable change kinds. `discover` finds devices,
  `browse` looks inside one and changes nothing, and `import` writes the config of the
  chosen tags into a file. The person decided on 2026-10-15 ("Ok this is good",
  https://github.com/synnaxlabs/foundation/issues/2705#issuecomment-6198173531), after
  asking: "Why does discover start modifying the config immediately? Isn't a 'browse
  to figure out what you want first' and then do a selector or an add/modify
  operation?" Supersedes `discover` as the step that writes the files.
